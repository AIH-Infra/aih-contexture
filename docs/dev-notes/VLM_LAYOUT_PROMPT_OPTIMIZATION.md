# VLM 版面识别提示词优化方案

## 问题分析

### 当前问题
1. **提示词过于简单**: 只列出标签名称，没有详细说明
2. **缺少视觉特征**: 没有描述块类型的大小、位置、格式特征
3. **缺少示例**: 没有提供具体的识别示例
4. **脚注识别混乱**: 特别是脚注与正文的区分不清

### VLM Direct 的优势
VLM Direct 模式有详细的脚注识别指导：
```
### 脚注识别（重点）
- 脚注通常在页面底部
- 字号明显小于正文
- 有编号标记（[1], ①, *）
- 与正文之间有分隔线或空白
```

## 优化方案

### 1. 增强块类型规范

为每种块类型添加详细说明：

#### Footnote (脚注)
**视觉特征**:
- 位置: 页面底部（通常在底部 10-20% 区域）
- 字号: 明显小于正文（通常是正文的 70-80%）
- 标记: 有编号标记（<sup>1)</sup>, [1], ①, *）
- 分隔: 与正文之间有分隔线或明显空白
- 对齐: 通常左对齐，可能有缩进

**与其他类型的区别**:
- vs Text: 字号更小，位于页面底部
- vs PageFooter: PageFooter 是页码/章节信息，Footnote 是注释内容
- vs Caption: Caption 紧邻图表，Footnote 在页面底部

#### PageHeader (页眉)
**视觉特征**:
- 位置: 页面顶部（通常在顶部 5-10% 区域）
- 内容: 章节标题、书名、页码
- 字号: 通常小于正文
- 分隔: 可能有下划线或空白分隔

#### PageFooter (页脚)
**视觉特征**:
- 位置: 页面底部（通常在底部 5-10% 区域）
- 内容: 页码、版权信息
- 字号: 通常小于正文
- 分隔: 可能有上划线或空白分隔

**与 Footnote 的区别**:
- PageFooter: 简短的页码/元信息
- Footnote: 较长的注释内容，有编号标记

#### Text (正文)
**视觉特征**:
- 位置: 页面主体区域
- 字号: 标准大小
- 对齐: 两端对齐或左对齐
- 行距: 标准行距

#### SectionHeader (章节标题)
**视觉特征**:
- 字号: 大于正文
- 字重: 加粗
- 位置: 段落开头或独立行
- 编号: 可能有章节编号

### 2. 优化提示词结构

```
第一部分: 任务说明
第二部分: 输出格式
第三部分: 块类型详细规范（新增）
第四部分: 识别规则和注意事项
```

### 3. 添加文档类型特定规则

#### 现代出版物
- 脚注在页面底部，有分隔线
- 页眉页脚简洁
- 章节标题明显

#### 学术论文
- 脚注密集，编号连续
- 可能有多栏布局
- 参考文献在文末

#### 古籍
- 可能有夹注（小字注释）
- 版心、边框等传统元素
- 竖排文字

## 实施建议

### 短期优化（立即可做）
1. 在现有模板中添加块类型详细说明
2. 特别强化 Footnote 的识别规则
3. 添加位置和大小的量化指标

### 中期优化
1. 为每种文档类型定制块类型规范
2. 添加更多示例
3. 引入置信度调整规则

### 长期优化
1. 基于实际识别结果优化提示词
2. 建立提示词版本管理
3. A/B 测试不同提示词效果

## 测试验证

### 测试用例
1. **脚注密集文档**: 学术论文、历史文献
2. **页眉页脚复杂**: 双页码、章节信息
3. **混合布局**: 多栏、图文混排

### 评估指标
1. **准确率**: 正确识别的块数 / 总块数
2. **召回率**: 正确识别的块数 / 实际块数
3. **混淆矩阵**: 特别关注 Footnote vs Text, PageFooter vs Footnote
