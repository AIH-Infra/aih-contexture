# 前端 UI 更新方案

## 需要修改的内容

### 1. 移除旧的配置项

**删除**：
- ❌ "锚点模板"下拉选择（固定使用 {n}）
- ❌ "页序起始值"数字输入（固定 0-based）

**原因**：简化方案固定使用 {n} 格式，不再支持模板变量

### 2. 保留的配置项

**保留**：
- ✅ "启用页码锚点"复选框
- ✅ "锚点位置"单选按钮（仅 VLM Direct 模式）
- ✅ "提取印刷页码"复选框
- ✅ 印刷页码详细配置（Pipeline 模式）

### 3. 新增配置项

**添加**：
- ✅ "自定义编号来源"下拉选择
  - 无
  - VLM 输出提取
  - 上传文件（CSV/JSON）
  - 手动输入列表
  - 自动生成

- ✅ 根据来源显示对应的配置界面

## 实施步骤

1. 找到页码锚点配置区域（约第 481-604 行）
2. 删除"锚点模板"和"页序起始值"配置
3. 添加"自定义编号配置"区域
4. 更新参数传递到后端
