# 仅 VLM 处理方案 - 使用指南

## 概述

通过现有的 UI 配置组合，实现"仅 VLM 处理"的效果：
- **版面识别后端** → 禁用版面识别
- **OCR 后端** → VLM
- **VLM 模式** → 整页

这样可以跳过传统的版面检测流程，直接用 VLM 处理整页，返回 Markdown。

## 配置步骤

### 1. 版面识别后端

选择：**🚫 禁用版面识别（仅 VLM 整页模式）**

这会跳过版面检测步骤，直接进行 OCR。

### 2. OCR 后端

选择：**🤖 VLM（视觉语言模型）**

配置 API：
- **Base URL**: `https://api.openai.com/v1` 或本地 LM Studio
- **模型名称**: `gpt-4o-mini` 或其他 VLM 模型
- **API Key**: 您的 API 密钥

### 3. VLM 模式

选择：**📄 整页（一次处理整页）**

这会让 VLM 一次性处理整个页面，而不是逐块处理。

### 4. 智能提示

当您选择"整页模式"时，UI 会自动提示：

- ✅ 如果已禁用版面识别：显示"完美配置"提示
- ⚠️ 如果未禁用版面识别：建议配合"禁用版面识别"使用

## 工作流程

```
传统方案：
PDF → Layout Detection → OCR → 结构化 → Markdown

仅 VLM 方案：
PDF → 提取页面图像 → VLM 整页处理 → Markdown
```

## 优势

1. ✅ **最简单**：跳过复杂的 pipeline
2. ✅ **最准确**：利用大模型的理解能力
3. ✅ **最灵活**：支持复杂文档、手写、古籍
4. ✅ **无需 GPU**：使用云端 API

## 故障排除

### 问题 1: 配置不生效

**症状**：选择了"禁用版面识别"，但仍然在进行版面检测

**解决**：
1. 确认 OCR 后端选择了 "VLM"
2. 确认 VLM 模式选择了 "整页"
3. 重新启动 Streamlit 应用

### 问题 2: API 错误

**症状**：VLM API 调用失败

**解决**：
1. 检查 API Key 是否正确
2. 检查 Base URL 是否可访问
3. 检查模型名称是否正确
4. 查看控制台日志获取详细错误信息

### 问题 3: 输出质量不佳

**症状**：转换结果不准确或格式混乱

**解决**：
1. 尝试使用更强大的模型（如 GPT-4o）
2. 调整图像质量参数
3. 自定义 VLM Prompt

## 技术实现

### UI 修改

1. **版面识别后端选项**：添加 "none" 选项
2. **智能提示**：当选择"整页模式"时提示配合"禁用版面识别"
3. **配置构建**：`build_config_dict` 中处理 `disable_layout`

### 配置传递

```python
config_params = {
    "layout_backend": "none",  # 禁用版面识别
    "ocr_backend": "vlm",      # 使用 VLM OCR
    "vlm_mode": "full_page",   # 整页模式
    # ... 其他配置
}

# build_config_dict 会将其转换为：
cli = {
    "layout_backend": "surya",      # 回退到 surya（但不会真正使用）
    "disable_layout": True,         # 标记禁用
    "ocr_backend": "vlm",
    "vlm_full_page_ocr": True,      # 启用整页 OCR
    # ...
}
```

### 工作流程

1. **加载文档**：提取所有页面图像
2. **跳过版面检测**：`disable_layout = True`
3. **VLM 整页处理**：`vlm_full_page_ocr = True`
4. **返回 Markdown**：直接输出结果
