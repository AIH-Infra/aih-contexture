### 1. ✅ AttributeError 错误
**问题**: `'OcrDirectAsyncConverter' object has no attribute 'ocr_endpoint'`

**原因**: 类中缺少属性默认值定义

**修复**: 在 `marker/converters/ocr_direct_async.py` 中添加了所有缺失的类属性：
- ocr_endpoint = "http://localhost:1234/v1"
- ocr_model = "chandra"
- ocr_api_key = None
- ocr_output_format = "json"
- ocr_max_tokens = 4096
- ocr_temperature = 0.1
- ocr_timeout = 120
- ocr_max_retries = 3
