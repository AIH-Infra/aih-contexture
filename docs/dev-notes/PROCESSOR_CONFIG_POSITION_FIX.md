## 重要说明

### ✅ 正确的显示逻辑

- **Pipeline 模式 + Surya Layout**：✅ 显示处理器配置
- **Pipeline 模式 + VLM Layout**：❌ 不显示（使用默认值）
- **Pipeline 模式 + YOLO Layout**：❌ 不显示（使用默认值）
- **VLM Direct 模式**：❌ 不显示（使用默认值）

### 为什么只在 Surya 下显示？

- Surya Layout 是最常用的 Pipeline 模式后端
- VLM 和 YOLO 用户较少，暂时使用默认值
- 未来可以扩展到其他后端
