# Streamlit UI 中使用 VLM Direct 模式 - 使用指南

## 概述

现在您可以在 Streamlit UI 中直接使用 **VLM Direct 异步并发模式**，完全跳过 Surya，纯用 VLM 处理。

## 🚀 快速开始

### 1. 启动 Streamlit UI

```bash
python marker_app.py
# 或
streamlit run marker/scripts/streamlit_app.py
```

### 2. 选择转换模式

在 UI 顶部找到 **"⚙️ 转换模式"** 部分，选择：

```
🚀 VLM Direct 模式（纯 VLM 异步并发）
```

### 3. 配置 VLM Direct

#### API 配置

- **Base URL**:
  - OpenAI: `https://api.openai.com/v1`
  - 通义千问: `https://dashscope.aliyuncs.com/compatible-mode/v1`
  - LM Studio: `http://localhost:1234/v1`

- **模型名称**:
  - OpenAI: `gpt-4o-mini` 或 `gpt-4o`
  - 通义千问: `qwen-vl-max`
  - LM Studio: 您的模型名称

- **API Key**: 您的 API 密钥

#### 并发配置

- **最大并发数**: 推荐 5-10
  - OpenAI 付费: 5-10
  - OpenAI 免费: 2-3
  - 通义千问: 5-10
  - Claude: 3-5
  - 本地 LM Studio: 1-2

### 4. 上传文件并转换

1. 上传 PDF 文件
2. 点击 **"🚀 开始转换"**
3. 等待转换完成
4. 下载结果

## 🎛️ 配置说明

### 基本配置

**必填项**：
- ✅ Base URL
- ✅ 模型名称
- ✅ API Key

**推荐配置**：
- 最大并发数: 5
- 图像最大边长: 2048
- JPEG 质量: 90

### 高级配置

#### 图像配置（展开 "🎨 图像配置"）

- **图像格式**: jpeg（推荐）/ png / webp
- **图像最大边长**: 512-4096（默认 2048）
- **JPEG 质量**: 1-100（默认 90）

#### API 调用配置（展开 "⚙️ API 调用配置"）

- **超时时间**: 30-600 秒（默认 180）
- **最大输出 token 数**: 512-16384（默认 8192）
- **最大重试次数**: 0-10（默认 3）

#### 提示词配置（展开 "📝 提示词配置"）

- 自定义 VLM 转换提示词
- 留空使用默认提示词

## 🔧 故障排除

### 问题 1：Rate Limit 错误

**症状**：
```
API error 429: Rate limit exceeded
```

**解决**：
- 降低并发数（从 5 降到 2）
- 等待一段时间后重试
- 升级 API 套餐

### 问题 2：API Key 错误

**症状**：
```
API error 401: Invalid API key
```

**解决**：
- 检查 API Key 是否正确
- 确认 API Key 有足够额度
- 检查 Base URL 是否正确

### 问题 3：超时错误

**症状**：
```
Timeout error on page X
```

**解决**：
- 增加超时时间（从 180 增加到 300）
- 降低图像分辨率
- 检查网络连接

### 问题 4：内存不足

**症状**：
```
MemoryError: Cannot allocate memory
```

**解决**：
- 降低图像分辨率（从 2048 降到 1536）
- 降低并发数
- 分批处理文档
