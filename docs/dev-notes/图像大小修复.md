# 图像大小修复 ✅

## 🎯 问题根源

LM Studio 报错：
```
"Cannot truncate prompt with n_keep (4476960) >= n_ctx (8192)"
```

**原因**：base64 编码的图像太大（~4.5MB），超过了 LM Studio 的上下文窗口（8192 tokens）

---

## ✅ 修复方案

### 1. 强制使用 JPEG 格式
**文件**: [marker/converters/ocr_direct_async.py](marker/converters/ocr_direct_async.py#L248)

```python
# ❌ 之前：使用 PNG（文件太大）
img.save(buffered, format="PNG")

# ✅ 现在：强制使用 JPEG + 优化
img.save(buffered, format="JPEG", quality=75, optimize=True)
```

### 2. 降低默认图像尺寸
```python
# ❌ 之前：2048px
ocr_resize_max = 2048

# ✅ 现在：1536px
ocr_resize_max = 1536
```

### 3. 降低 JPEG 质量
```python
# ❌ 之前：95
ocr_image_quality = 95

# ✅ 现在：75
ocr_image_quality = 75
```

---

## 📊 预期效果

**之前**：
- 图像尺寸：2048px
- 格式：PNG
- Base64 大小：~4.5MB
- 结果：❌ 超过上下文窗口

**现在**：
- 图像尺寸：1536px
- 格式：JPEG (quality=75)
- Base64 大小：~200-500KB
- 结果：✅ 适合 LM Studio
