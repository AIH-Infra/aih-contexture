# 页码锚点系统 - 关键决策点

## 决策 1：页码锚点的表示方式

### 当前方案
- `{n}` = 0-based（0, 1, 2...）
- `{n1}` = 1-based（1, 2, 3...）
- 每页开头添加锚点

### 您提出的新方案
- 保持 `{n}` 从 0 开始
- 在文档末尾添加额外锚点（如最后一页是第2页，则添加 {3}）
- 这样 {0}-{1} 之间是第一页，{1}-{2} 之间是第二页

### 建议
**两种方案共存**：
- 保留 `{n}` 和 `{n1}` 用于传统页码标记
- 添加新选项："在文档末尾添加额外锚点"（用于区间表示）

**您的决策**：
- [ ] 只用新方案（区间表示）
- [ ] 只用旧方案（传统页码）
- [ ] 两种方案共存（推荐）

## 决策 4：分隔符和包裹符号

### 分隔符：- vs _

**示例**：
- 使用 `-`：`{custom-or-n1}`, `{printed-or-n1}`
- 使用 `_`：`{custom_or_n1}`, `{printed_or_n1}`

**建议**：使用 `-`（更常见，更易读）

**您的决策**：
- [ ] 使用 `-`（推荐）
- [ ] 使用 `_`
- [ ] 允许用户自定义

### 包裹符号

**当前**：`{}`（如 `{1}`, `{sc001}`）

**其他选项**：
- `[]`：`[1]`, `[sc001]`（可能与 Markdown 链接冲突）
- `()`：`(1)`, `(sc001)`（可能与 Markdown 链接冲突）
- `<>`：`<1>`, `<sc001>`（可能与 HTML 冲突）
- 自定义：用户指定

**建议**：保持 `{}`，但允许用户自定义

**您的决策**：
- [ ] 固定使用 `{}`
- [ ] 允许用户自定义（推荐）
