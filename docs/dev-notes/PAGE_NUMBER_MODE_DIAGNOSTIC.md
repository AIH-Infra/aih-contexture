# 印刷页码提取配置诊断

## 当前问题

您勾选了"提取印刷页码"，但：
1. ❌ 没有显示详细配置选项（页码搜索区域、页码格式等）
2. ❌ 日志显示 `use_printed_page_number=False`

## 诊断步骤

### 步骤 1：确认转换模式

在 Streamlit UI 顶部，查看您选择的转换模式：

- **Pipeline 模式**：传统的 PDF 转换流程（Surya 布局 + OCR）
- **VLM Direct 模式**：直接使用 VLM 模型转换

**请确认您当前使用的是哪个模式。**

### 步骤 2：根据模式检查配置

#### 如果您在 Pipeline 模式：

勾选"提取印刷页码"后，**应该显示**以下详细配置选项：
- 页码搜索区域（multiselect）
- 页码格式（selectbox）
- 页眉起始位置（slider）
- 页眉结束位置（slider）
- 页脚起始位置（slider）

**如果这些选项没有显示，说明有 UI 渲染问题。**

#### 如果您在 VLM Direct 模式：

勾选"提取印刷页码"后，**不会显示**详细配置选项。

VLM Direct 模式使用固定的默认配置：
- 页码搜索区域：`["footer", "header"]`
- 页码格式：`"auto"`（自动检测）

### 步骤 3：检查配置传递

无论哪个模式，勾选"提取印刷页码"后，日志应该显示：

```
[PageNumberProcessor] Config: use_printed_page_number=True
```

**如果显示 `False`，说明配置传递有问题。**

## 可能的原因

### 原因 1：UI 状态不同步

**症状：** 勾选了选项，但刷新页面后配置丢失

**解决方法：**
1. 重新勾选"启用页码锚点"
2. 重新勾选"提取印刷页码"
3. 立即点击"开始转换"（不要刷新页面）

### 原因 2：转换模式不匹配

**症状：** 在 VLM Direct 模式下，但期望看到 Pipeline 模式的详细配置

**解决方法：**
1. 切换到 Pipeline 模式
2. 重新勾选选项
3. 查看是否显示详细配置

### 原因 3：配置传递逻辑有 bug

**症状：** 勾选了选项，但日志显示 `use_printed_page_number=False`

**解决方法：**
1. 查看完整的日志输出
2. 确认是否有其他错误信息
3. 检查配置是否被覆盖

## 快速测试方法

### 方法 1：使用 Pipeline 模式

1. 选择 **Pipeline 模式**
2. 勾选 **"启用页码锚点"**
3. 勾选 **"提取印刷页码"**
4. **确认显示详细配置选项**
5. 页码搜索区域：选择 `header` 和 `footer`
6. 页码格式：选择 `auto`（自动检测）
7. 点击"开始转换"
8. 查看日志，确认 `use_printed_page_number=True`

### 方法 2：使用 VLM Direct 模式

1. 选择 **VLM Direct 模式**
2. 勾选 **"启用页码锚点"**
3. 勾选 **"提取印刷页码"**
4. **不会显示详细配置选项**（这是正常的）
5. 点击"开始转换"
6. 查看日志，确认 `use_printed_page_number=True`
