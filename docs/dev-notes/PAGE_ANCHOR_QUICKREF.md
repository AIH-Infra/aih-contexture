# 页码锚点快速参考

## 一、核心概念

### 什么是页码锚点？

页码锚点是插入在每页开头的标记，用于：
- **精确引用**: 在学术文献中引用特定页面
- **快速跳转**: 在长文档中快速定位
- **结构化**: 保持文档的页面结构信息

**示例**:
```markdown
{0}

# 第一章 引言

这是第一页的内容...

---

{1}

## 1.1 背景

这是第二页的内容...
```

## 二、配置选项

### 2.1 锚点模板

| 模板 | 说明 | 示例输出 | 适用场景 |
|------|------|---------|---------|
| `{n}` | 0-based 页序 | `{0}`, `{1}`, `{2}` | 编程、技术文档 |
| `{n1}` | 1-based 页序 | `{0}`, `{1}`, `{2}` | 通用文档 |
| `{printed}` | 仅印刷页码 | `{XII}`, `{308}` | 古籍、特殊编号 |
| `{printed-or-n1}` | 优先印刷页码 | `{XII}` 或 `{1}` | **推荐：人文学科** |
| `{printed} ({n1})` | 组合显示 | `{XII (1)}` | 需要双重引用 |

### 2.2 页序起始值

- **0**: 第一页显示为 0（编程习惯）
- **1**: 第一页显示为 1（学术习惯，**推荐**）

### 2.3 锚点位置

- **before**: 页面前（**推荐**）
- **after**: 页面后
- **both**: 页面前后都有

### 2.4 印刷页码提取

- **启用**: 自动从 VLM 输出中提取印刷页码
- **禁用**: 不提取，仅使用页序

## 三、使用场景

### 场景 1: 现代学术论文

**需求**: 标准页码，从 1 开始

**配置**:
```
模板: {n1}
起始值: 1
位置: before
提取印刷页码: 否
```

**输出**:
```markdown
{1}

# Abstract

This paper presents...

---

{2}

# Introduction

In recent years...
```

### 场景 2: 古籍文献

**需求**: 使用原书页码（如罗马数字），无页码时用序号

**配置**:
```
模板: {printed-or-n1}
起始值: 1
位置: before
提取印刷页码: 是
```

**Prompt 增强**:
```
If you see a page number in the header or footer, include it as:
<!-- printed-page: XII -->
```

**输出**:
```markdown
{XII}

序

本书初版于...

---

{XIII}

目录

第一章...

---

{1}

第一章 绪论

（此页无印刷页码，使用序号）
```

### 场景 3: 档案馆文献

**需求**: 双重页码（���始页码 + 序号）

**配置**:
```
模板: {printed} ({n1})
起始值: 1
位置: before
提取印刷页码: 是
```

**输出**:
```markdown
{308 (1)}

档案编号: 1949-A-0308

内容：...

---

{309 (2)}

（续上页）
```

### 场景 4: 技术文档

**需求**: 简单的 0-based 索引

**配置**:
```
模板: {n}
起始值: 0
位置: before
提取印刷页码: 否
```

**输出**:
```markdown
{0}

# API Documentation

## GET /api/users

---

{1}

## POST /api/users
```

## 四、VLM Direct 中的印刷页码提取

### 4.1 Prompt 设计

在 VLM Direct 的 prompt 中添加页码标注指令：

```
Convert this document page to Markdown format.

Requirements:
1. Preserve the exact structure and formatting
2. Use proper Markdown syntax...
3. **If you see a page number (printed page number) in the header or footer,
   include it as a comment at the very beginning:**
   <!-- printed-page: XII -->
   or
   <!-- printed-page: 308 -->
4. Do NOT add any other explanations or comments
5. Output ONLY the Markdown content

Example output:
<!-- printed-page: XII -->

# Chapter 1

Content here...
```

### 4.2 支持的标记格式

系统自动识别以下格式：

```markdown
<!-- printed-page: XII -->
<!-- page: 308 -->
[页码: 12]
```

### 4.3 自动处理流程

```
VLM 输出:
<!-- printed-page: XII -->

# 第一章

内容...

↓ 自动提取

提取到: printed_page = "XII"

↓ 清理标记

# 第一章

内容...

↓ 添加锚点

{XII}

# 第一章

内容...
```

## 五、UI 操作指南

### 5.1 启用页码锚点

1. 选择 **VLM Direct 模式**
2. 展开 **📍 页码锚点配置**
3. 勾选 **启用页码锚点**

### 5.2 配置锚点格式

1. **锚点模板**: 选择页码显示格式
   - 推荐人文学科: `{printed-or-n1}`
   - 推荐现代文档: `{n1}`

2. **页序起始值**:
   - 学术文献: 选择 `1`
   - 技术文档: 选择 `0`

3. **锚点位置**:
   - 通常选择 `页面前`

4. **提取印刷页码**:
   - 古籍/档案: 勾选
   - 现代文档: 不勾选

### 5.3 配置 Prompt（如需提取印刷页码）

1. 展开 **📝 提示词配置**
2. 在自定义提示词中添加页码标注指令（见 4.1）
3. 或留空使用默认 prompt

## 六、常见问题

### Q1: 锚点未显示？

**A**: 检查以下项：
1. 是否勾选了"启用页码锚点"
2. 查看日志中是否有 "Adding page anchors..." 信息
3. 确认转换成功完成

### Q2: 印刷页码未提取？

**A**:
1. 确认勾选了"从 VLM 输出提取印刷页码"
2. 检查 prompt 中是否包含页码标注指令
3. 查看日志中 "Found X printed pages" 的数量
4. 验证 VLM 输出的标记格式是否正确

### Q3: 锚点格式不对？

**A**:
1. 检查"锚点模板"选择是否正确
2. 确认"页序起始值"设置
3. 如果使用印刷页码，确认提取是否成功

### Q4: 如何在 Markdown 中跳转到特定页？

**A**:
大多数 Markdown 编辑器支持搜索功能：
1. 按 Ctrl+F 打开搜索
2. 输入 `{5}` 跳转到第 5 页
3. 或使用编辑器的"转到行"功能

### Q5: 可以自定义锚点格式吗？

**A**:
当前版本支持的格式：
- 包装: `{...}` (固定)
- 模板: 5 种预设模板
- 位置: before/after/both

如需更多自定义，可以修改代码中的 `PageAnchorFormatter`。

## 七、最佳实践

### ✅ 推荐做法

1. **人文学科/档案馆**:
   - 模板: `{printed-or-n1}`
   - 起始值: `1`
   - 提取印刷页码: `是`
   - 原因: 保留原始页码，符合学术引用规范

2. **现代学术论文**:
   - 模板: `{n1}`
   - 起始值: `1`
   - 提取印刷页码: `否`
   - 原因: 简洁清晰，符合通用习惯

3. **技术文档**:
   - 模板: `{n}`
   - 起始值: `0`
   - 提取印刷页码: `否`
   - 原因: 符合编程习惯

### ❌ 避免做法

1. **不要**在不需要时启用印刷页码提取
   - 会增加处理时间
   - 可能误识别

2. **不要**使用 `{printed}` 模板而不提取印刷页码
   - 会导致所有页面锚点为空

3. **不要**在快速原型时使用复杂模板
   - 简单的 `{n}` 或 `{n1}` 即可

## 八、技术细节

### 8.1 锚点格式

标准格式: `{content}`

其中 `content` 由模板决定：
- `{n}`: 0, 1, 2, ...
- `{n1}`: 0, 1, 2, ... (起始值可配置)
- `{printed}`: XII, 308, ...
- `{printed-or-n1}`: XII 或 1
- `{printed} ({n1})`: XII (1)

### 8.2 处理流程

```
1. VLM 转换页面 → Markdown
2. 提取印刷页码（如启用）
3. 清理页码标记
4. 添加页码锚点
5. 拼接所有页面
6. 输出最终 Markdown
```

### 8.3 性能影响

- 页码锚点添加: **几乎无影响** (<0.1s)
- 印刷页码提取: **轻微影响** (~0.1-0.5s)
- 总体: **可忽略不计**

```markdown
# 第一章 引言

这是第一页的内容...

---

## 1.1 背景

这是第二页的内容...
```

**问题**: 无法快速定位特定页面

这是第二页的内容...
```

**优势**: 可以搜索 `{1}` 快速跳转

# 第一章 引言

（正文从第 1 页开始）
```

**优势**: 保留原始页码，符合学术引用

## 十、总结

页码锚点是"兰台·PageAnchor"项目的核心功能，为人文学科和档案馆提供了：

✅ **精确引用**: 支持学术规范的页码引用
✅ **灵活配置**: 5 种模板，适应不同场景
✅ **印刷页码**: 自动识别和使用原始页码
✅ **易于使用**: UI 配置，无需编程
✅ **高性能**: 几乎无性能影响

**推荐配置**（人文学科）:
- 模板: `{printed-or-n1}`
- 起始值: `1`
- 位置: `before`
- 提取印刷页码: `是`
