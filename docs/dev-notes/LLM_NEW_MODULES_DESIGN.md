# LLM 新增模块设计 - 降噪与印刷页码修正

## 新增模块概述

### 1. 智能降噪 (LLMNoiseRemoval)
- **功能**: 识别并过滤无关符号和语言
- **处理粒度**: 块级 (Block-level)
- **集成位置**: 块内DAG处理

### 2. 印刷页码修正 (LLMPrintedPageCorrection)
- **功能**: 启发式识别和修正印刷页码
- **处理粒度**: 跨块级 (Cross-chunk)
- **集成位置**: 跨块后处理

## 与混合方案的集成

### 完全兼容，不冲突！

**混合方案:**
- **方案A（分块）**: 解决空间问题，防止OOM
- **方案B（DAG）**: 解决时间问题，优化任务调度

**新功能集成:**
- **智能降噪**: 在每个chunk的DAG中执行（块级并行）
- **印刷页码修正**: 在所有chunk处理完成后执行（跨块分析）

### 处理流程

```
1. 文档分块（方案A）
   - 1000页 -> 100个chunk（每10页）

2. 块内并行处理（方案B）
   每个chunk内:
   - 表格优化（块级，并行）
   - 公式识别（块级，并行）
   - 智能降噪（块级，并行）<- 新增
   - 手写识别（块级，并行）
   - 页面校正（页级，依赖布局）

3. 跨块后处理
   - 印刷页码修正（跨块分析）<- 新增
   - 段落合并（跨页处理）
   - 目录生成（全局分析）

4. 最终组装
   - 按页码顺序组装 -> Markdown
```

## 智能降噪详细设计

### 应用场景
- 扫描文档中的污渍、水印残留
- OCR 误识别的随机字符
- 与主要语言不符的零散字符
- 页边装饰性符号
- 无意义的重复字符

### 处理策略
1. 提取文本块内容
2. 获取上下文（前后块）
3. 检测文档主要语言
4. LLM判断是否为噪音
5. 根据建议采取行动（移除/保留/修正）

### 配置参数
- `llm_noise_removal_enabled`: bool（默认False）
- `noise_confidence_threshold`: float（默认0.7）
- `noise_removal_action`: str（默认"mark"）
