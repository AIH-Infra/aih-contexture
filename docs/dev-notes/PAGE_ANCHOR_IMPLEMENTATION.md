# 简化页码锚点方案 - 实现评估

## 📋 方案总结

### 核心设计
1. **固定使用 `{n}` 格式**（0-based，从 0 开始）
2. **在文档末尾添加额外锚点**
3. **统一使用 `<!-- Page: X -->` 格式**
4. **取消复杂模板变量系统**

### 最终效果
```
{0}
<!-- Page: B132 -->
第一页内容...

{1}
<!-- Page: 132 --><!-- Page: sc002 -->
第二页内容...

{2}  ← 额外锚点
```

## ✅ 结论：推荐采用

### 优点
1. 大幅简化代码
2. 统一格式
3. 便于编程处理（区间提取）
4. 易于维护

### 注意事项
1. 页码标记可见（HTML注释）
2. 需要修改现有行为
3. 建议添加"清理标记"选项

### 5种自定义编号来源
1. VLM 输出提取（自动识别）

3. 手动输入列表
4. 自动生成（前缀+编号+补零）
5. 无
